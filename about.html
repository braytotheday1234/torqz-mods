About Torqz Mods

Build the system.
Show the progress.

Torqz Mods is a new independent BeamNG.drive modding project. Right now, the focus is Torqz Garage — Project 01 — and the systems needed for persistent vehicle ownership.

What Torqz Builds / 01

BeamNG systems with a reason to exist.

Torqz Garage is not another vehicle pack. It is being designed as a gameplay and utility system that can give vehicles identity, history, and ownership data across gameplay.

The current Vehicle Data phase focuses on detection and telemetry foundations before persistence features are treated as real.

Why Torqz Exists / 02

Make BeamNG projects easier to understand.

A good mod should explain what it does, what is still planned, what version it supports, how it installs, and where development stands.

Torqz uses the website as part of the development process instead of waiting until release day to explain everything.

Project 01 / 04

Torqz Garage is the current focus.

Project 01 remains the internal development identifier. Torqz Garage is the public project name and the site is structured so real screenshots, telemetry tests, milestones, logs, compatibility data, and release information can be added without another redesign.
