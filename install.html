General guidance only

Before installing other BeamNG mods.

These are general checks for already-released mods—not installation instructions for Torqz Garage.

  1. Use the official creator's release files and instructions.
  2. Confirm your BeamNG version and the mod's published compatibility details.
  3. Locate your active BeamNG user folder through the launcher if needed.
  4. Follow the creator's instructions for archive placement; avoid guessing folder paths.
  5. Check Mod Manager and messages after starting the game.
