Installation

Install with
the project guide.

Torqz projects can use different installation methods. The project page is the source of truth for the real steps, paths, warnings, and release-specific notes.

01

Open the Project

Start on the Torqz project page so you can see its current release status, compatibility, and actual installation information.

02

Check Compatibility

Do not assume a project supports your current BeamNG.drive version. Use the compatibility information published for that release.

03

Follow Its Steps

Use only the installation steps configured for that project. Paths, warnings, dependencies, and special notes can differ between releases.

04

Use Support if Needed

If the project has known issues or support notes, check those before changing files or troubleshooting beyond the documented method.
