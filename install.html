Installation

Four steps.
No confusion.

The standard Torqz release flow is intentionally simple. Project pages will always call out any exception before you download.

01

Download

Use the official download link on the Torqz project page once the release is available.

02

Move File

Keep the archive zipped unless the specific project notes tell you to extract or install it another way.

03

Place in Mods

Open the active BeamNG.drive user folder and move the ZIP into its mods folder.

04

Launch BeamNG

Start the game and confirm the project appears. Check compatibility and known issues on the project page before deeper troubleshooting.

Typical path

BeamNG user-folder mods directory

The exact version folder can vary, so use the BeamNG launcher to manage or open the active user folder when possible.

%LOCALAPPDATA%\BeamNG.drive\<version>\mods
