Installation

Use the project
release guide.

Torqz projects can use different installation methods. Each project page becomes the source of truth when a real release method, path, warning, or dependency is verified.

01

Open the Project

Start on the project page and confirm its release state before downloading or moving any files.

02

Check Compatibility

Use the tested BeamNG.drive version listed for that release. If compatibility still says TBD, it has not been verified yet.

03

Follow Its Steps

Paths, extraction rules, dependencies, and warnings can differ between projects, so installation is stored per project.

04

Check Known Issues

Review published issues and support notes before changing files or troubleshooting outside the documented process.
