Installation

Install Torqz mods cleanly.

The download experience is designed around a straightforward ZIP-mod workflow, with release-specific exceptions called out on the individual mod page.

01

Use the official Torqz download

Download from the mod detail page once an official release exists. Avoid third-party reuploads when an original Torqz source is available.

02

Keep the ZIP intact

Unless the release notes specifically require another method, keep the downloaded mod archive zipped.

03

Open the current BeamNG user folder

Use the BeamNG.drive launcher to manage or open the current user folder, then locate the mods folder for that user folder.

04

Move the mod into the mods folder

Place the Torqz ZIP inside the mods folder. Keep the original folder structure intact.

05

Launch and verify

Start BeamNG.drive and confirm the mod appears. If something is wrong, check the mod page for compatibility notes and known issues first.

Before troubleshooting

Check the release page first.

Every finished Torqz release is intended to list its tested BeamNG.drive version, installation notes, dependencies, and known issues in one place.
