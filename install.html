Install a Torqz Mod

Simple release instructions designed around BeamNG.drive's normal ZIP-mod workflow.

STEP 01

Download

Use the official download button on the Torqz project page. Avoid reuploads.

STEP 02

Keep the ZIP

Unless a release specifically says otherwise, keep the mod archive zipped.

STEP 03

Open User Folder

Use the BeamNG launcher to manage/open your current user folder and locate the mods folder.

STEP 04

Launch & Check

Start BeamNG.drive, verify the mod appears, and check the project page if there are compatibility notes.
